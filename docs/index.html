QM Intake

QM Intake is an application for rapid intake into the private Chateau Lore Quartermaster application.

It will not work without privately provisioned credentials. Installing the app does not grant access to Quartermaster.

Install APK ↓ Add with Obtainium

QM Intake 0.3.0 · Requires Android 9 or newer.

Version 0.3.0 adds an optional expiration date picker with a clear button and saves the date in recovered drafts. Expiration dates require Quartermaster 1.0.

Android: install and connect

  1. Download the APK on your Android device and open it. If prompted, allow your browser to install apps, then tap Install.
  2. Open QM Intake Settings and enter the server address, device ID, and secret provided privately for your device.
  3. Tap Save and test connection.

If Obtainium is already installed, the button above adds this release repository for updates. Otherwise, install Obtainium first, then return to this page.

iOS: install with SideStore

Add to SideStoreDownload iOS IPA ↓

iOS 0.3.0 (build 1) · Requires iOS 17 or newer.

  1. On your iPhone, tap Add to SideStore, confirm the source, then install QM Intake from its listing. Future iOS releases appear as updates in SideStore. QM Intake has no app extensions.
  2. Open QM Intake Settings and enter the privately issued server address, device ID, and secret for this phone.
  3. Tap Save and test connection. Refresh the app through SideStore before its signing period expires.

Already installed from a local IPA? Install or update from the source using the same Apple account; do not delete QM Intake first. See the SideStore update guide. Manual source URL: apps.json.
